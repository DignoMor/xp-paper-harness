# Changelog

## 1.0.0 — 2026-10-19

First release of Paper Harness, a local-first environment for academic Papers.

- Import staged PDFs into an external filesystem Library with stable Paper and Attachment identities, duplicate detection, bibliographic metadata, and multiple Attachments per Paper.
- Read and search bounded, page-numbered PDF text through a Paper Agent with a closed inventory of semantic tools and an environment-configured OpenCode Go provider.
- Maintain portable Markdown Paper Notes with atomic, revision-checked edits and managed frontmatter.
- Create, resume, and rename durable Conversations in a browser with streamed responses, PDF viewing, and rendered/raw note viewing.
- Diagnose Library integrity through report-only reconciliation, optional deep hash verification, and explicit safe note repairs.
- Start with Docker Compose using external data storage and loopback-only host publication; disclose cloud provider use in the UI.
- Harden Conversation path validation, interrupted-log recovery, concurrent response handling, provider tool streaming, error disclosure, Markdown rendering, and Catalog integrity validation.
